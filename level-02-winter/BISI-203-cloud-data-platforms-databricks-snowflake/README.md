# BISI-203: Enterprise Cloud Data Platforms (Databricks, Snowflake & IaC)

* **Course Code:** BISI-203
* **Contact Hours:** 56.0 Hours (4.0 hrs/week × 14 weeks)
* **Delivery Mode:** Cloud Architecture Lab
* **Prerequisites:** BISI-103, BISI-106

---

## 1. Course Description
Explores commercial cloud data platforms utilized extensively across enterprise public administration: **Databricks Lakehouse** and **Snowflake Data Cloud**. Students configure Databricks Unity Catalog for centralized governance, column masking, and data lineage tracking. In Snowflake, students build virtual warehouses, configure Snowpipe for continuous auto-ingestion, and leverage Zero-Copy Cloning and Time Travel for zero-risk testing. All cloud objects are managed as code using **Terraform**.
