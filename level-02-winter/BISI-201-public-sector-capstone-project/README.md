# BISI-201: Public Sector Big Data Capstone Project

* **Course Code:** BISI-201
* **Contact Hours:** 84.0 Hours (6.0 hrs/week × 14 weeks)
* **Delivery Mode:** Agile Studio / Client Consultancy
* **Prerequisites:** All Level 01 Courses

---

## 1. Course Description
The culminating experiential learning project. Multidisciplinary student teams function as agile data engineering consultancies embedded with external public sector, municipal, or crown corporation clients. Teams take a complex, unstructured problem from initial requirements gathering through to a fully automated, sovereign-cloud-deployed Big Data and Business Intelligence platform with executive defense.
