# BISI-204: Big Data Modelling, Data Mesh & Master Data Management (MDM)

* **Course Code:** BISI-204
* **Contact Hours:** 56.0 Hours (4.0 hrs/week × 14 weeks)
* **Delivery Mode:** Modeling Studio / Data Architecture Lab
* **Prerequisites:** BISI-102, BISI-106

---

## 1. Course Description
Addresses large-scale information modeling challenges. Students master **Data Vault 2.0** modeling (Hubs, Links, Satellites) to build historically auditable public administration repositories that support zero-downtime schema evolution. The course covers **Master Data Management (MDM)**, record linkage, and probabilistic entity resolution across disparate municipal and federal databases. Finally, students implement the decentralized **Data Mesh** paradigm, defining domain ownership boundaries and data-as-a-product SLA contracts.
