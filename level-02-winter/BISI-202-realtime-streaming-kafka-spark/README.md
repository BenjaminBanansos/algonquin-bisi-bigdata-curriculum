# BISI-202: Real-Time Analytics & Streaming Architectures (Kafka & Spark)

* **Course Code:** BISI-202
* **Contact Hours:** 56.0 Hours (4.0 hrs/week × 14 weeks)
* **Delivery Mode:** Lab-Intensive / Systems Engineering
* **Prerequisites:** BISI-101, BISI-102

---

## 1. Course Description
Examines high-throughput event streaming architectures. Students deploy and administer **Apache Kafka** clusters, configure topics, partitions, replication factors, and schema enforcement using Confluent Schema Registry (Avro). Real-time stream processing is implemented using **Spark Structured Streaming**, focusing on event-time vs. processing-time, tumbling and sliding window aggregations, watermarking to handle delayed data packets, and streaming writes into Delta Lake ACID tables.
